Open Source · Security

SmartHome Security Auditor

Собственный open-source CLI-инструмент (MIT) для аудита безопасности умного дома. Сам находит IoT-устройства в сети и прогоняет 40+ проверок: дефолтные пароли, HTTP/HTTPS, SSL, telnet/SSH, UPnP, CORS, известные CVE. Поддержка Home Assistant, Tuya, Xiaomi, Zigbee, MQTT. Отчёты в HTML/JSON/консоль, Telegram-алерты на critical-находки. Python 3.11 + async, модульная архитектура, Rich, pytest. Доказывает, что за n8n стоит системный Python.
